# Abast-gp V6 - User Training Plan

## 1. Alcance
Capacitar a los operadores logísticos y supervisores para convivir eficientemente con los motores de Inteligencia Artificial (OCR + RAG), erradicando las malas prácticas documentales que merman la efectividad algorítmica.

## 2. Módulo A: Buenas Prácticas de OCR (Document Quality)
**Público:** Operadores (Mesa de Partes, Logística).
- **Regla de Oro:** "Basura entra, basura sale". 
- Configurar escáneres físicos a un **mínimo de 300 DPI**.
- Eliminar páginas en blanco de los PDFs (Ahorra tiempo de procesamiento).
- Entender el Scorecard: Qué hacer si el semáforo arroja ⚠️ (Warning) o ❌ (Blocked).

## 3. Módulo B: Convivencia con la IA RAG
**Público:** Especialistas de Adquisiciones.
- **Limitaciones del RAG:** El RAG busca, no inventa. Si el Contrato (Anexo 3) no dice explícitamente "Servicio de Limpieza", el RAG podría no calcular el monto.
- **Interpretación de Evidencia:** Cómo leer la justificación del Motor. El humano SIEMPRE debe clickear en el Snippet (Texto extraído) para corroborar que el monto sugerido por la máquina existe en el papel original antes de presionar `VALIDAR`.

## 4. Módulo C: Gobierno Transaccional
**Público:** Supervisores, OGA.
- Cómo usar el Dashboard de Priorización.
- Qué implica presionar el botón `SUPERVISOR_EXCEPTION_SELECT` (Alerta a Contraloría).
- Generación y análisis del CSV Operacional para Comités.
