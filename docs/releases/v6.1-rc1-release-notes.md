# Abast-gp V6.1-RC1 Release Notes

**Version:** 6.1-rc1
**Date:** 2026-08-09
**Status:** Feature Freeze / Release Candidate

## 1. Novedades (Features)
- **Admin Governance Dashboard & API**: Las instituciones ya no dependen de soporte externo para alterar la agresividad del RAG (`min_rag_confidence`) o el bloqueo óptico del OCR (`min_dpi_threshold`). Cuentan con un panel propio resguardado por RBAC (`ADMIN_IT_INSTITUCIONAL`).
- **Configuration Versioning**: Toda alteración administrativa queda versionada con historial, permitiendo auditorías de contraloría sobre "Quién bajó la tolerancia del OCR antes de adjudicar".
- **Sovereign Telemetry (Scheduler)**: Motor asíncrono (Celery Beat) para recopilar métricas de rendimiento y calidad de IA sin extraer contratos ni nombres. Protegido por una estricta política *Opt-In* local.

## 2. Mejoras de Seguridad y Roles
- **Multi-Tenant Isolation Garantizado**: Se introdujo el rol `SYSTEM_ADMIN` para soporte técnico L3 de Abast-gp, pero se ha codificado explícitamente su ceguera multi-tenant.
- **Break Glass Access**: Los incidentes P1 ahora pueden ser atendidos por L3 usando tokens temporales de emergencia (2 horas) previa autorización local.

## 3. Resolución de Riesgos Previos
- La carga de los *Workers* ha sido segmentada. La adición de `celery_beat` al `docker-compose.yml` desvincula la calendarización de tareas de la memoria de la API principal, evitando latencia para los operadores durante la exportación de telemetría.

## 4. Disposiciones de Despliegue
- La V5.5 transaccional permanece inalterable bajo el capó.
- Listo para despliegue en oficinas piloto.
