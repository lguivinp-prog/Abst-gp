# Abast-gp V6.0-RC1 Release Notes

**Version:** 6.0.0-rc1
**Date:** 2026-08-09
**Status:** Feature Freeze

## 1. Alcance y Resumen Ejecutivo
Abast-gp V6.0-RC1 es el Release Candidate oficial para despliegue en entornos de Producción Local. Incorpora toda la cadena de Inteligencia Documental (Requerimientos, Proveedores, Ofertas, y Experiencia), orquestada por asistentes IA basados en RAG seguro, y encapsulada bajo un Dashboard de Supervisión Ejecutiva.

Desde este momento, el código entra en **Feature Freeze**. No se aceptarán cambios funcionales ni arquitectónicos, reservando futuros _commits_ estrictamente para parches de estabilidad o bloqueos de seguridad.

## 2. Componentes Entregados
- **Requirement Intelligence**: Extracción OCR/Heurística del TDR.
- **Supplier Intelligence & External Validation**: Adaptadores Híbridos para SUNAT, RNP, FUP y CIIU (API y Fallback manual).
- **Offer Evaluation**: Evaluación matemática de anexos con validación de precios.
- **Experience Intelligence**: Lectura restringida de experiencia (Anexo 3, Contratos) evaluada contra Requerimiento.
- **Secure RAG AI Assistant**: Chat RAG 100% circunscrito a los documentos (DocumentChunks) del caso activo del Tenant.
- **Decision Workflow & Output Engine**: Árbol de decisión y generación documental avalada por el `ContractAccuracyGate`.
- **Supervisor Dashboard**: Capa superior determinista con semáforos de riesgo y Bandeja de Aprobación, priorizada sin IA.

## 3. Compatibilidad Backward (V5.5)
- El core transaccional certificado de la V5.5 (Recovery Engine, Disaster Recovery) permanece estricta y absolutamente **INTACTO**. La V6 opera mediante _Sidecars_ y módulos _Plug-in_ aislados de las tablas core V5, preservando la garantía SLA de recuperación legal del Estado.
