# Abast-gp V6.1 - Guía de Operaciones Institucional

## 1. Instalación (Deployment)
El sistema ahora incluye un contenedor `celery_beat` responsable de las tareas programadas (Telemetría Soberana). 
Para iniciar todo el Stack V6.1 de forma aislada:
```bash
docker-compose -f deploy/docker-compose.yml up -d
```

## 2. Parada Segura (Graceful Stop)
Para apagar el sistema sin corromper tareas de OCR en curso:
```bash
docker-compose -f deploy/docker-compose.yml stop
```

## 3. Logs y Monitoreo (SRE)
- **Log API Transaccional**: `docker-compose logs -f api`
- **Log OCR/RAG**: `docker-compose logs -f celery_worker`
- **Log Telemetría**: `docker-compose logs -f celery_beat`

## 4. Recuperación (Recovery) ante OOM
Si el contenedor `celery_worker` muere por Out-Of-Memory procesando un contrato masivo, el `celery_beat` y el `api` seguirán operando.
Comando de resurrección aislada:
```bash
docker-compose restart celery_worker
```
